Finding the move is not winning the game

Starting from 119 tactical endgames with forced mates, an LLM agent must deliver checkmate against an engine defender. It acts through a REPL that separates real moves, state queries and forward simulation, and is scored only on whether it delivers mate.

Models
12 frontier LLMs, two observation protocols
Data
8,568 multi-turn trajectories
Authors
Yekun Chai, Qiwei Peng, Haoyi Xiong
Read the paper

Three signals that look like competence each overstate closed-loop success.

Conversion gap
26.1% → 13.9%
Models play the reference first move in 26.1% of sighted trials; only 13.9% of those trials end in a win.
Consistency gap
38.7% vs 5.9%
The leading model reaches 38.7% pass@3 but only 5.9% pass^3, winning all three trials on 7 of 46 positions.
Simulation gap
49.3%
Of comparable cases, the real defender replies differently from the line the agent simulated.

Questions we keep coming back to

Each study targets one question and ships with its harness and data.

What is a repeated token worth?

Public text grows more slowly than compute. We price a repeated token against fresh data and find the epoch count past which it is worth half as much, across models from 14M to 2B parameters.

Can an agent finish the game, not just find the move?

The agent plays a full game against an engine through a small command protocol, under per-turn budgets, and is scored on the final outcome.

XiangqiBench →

What do models know about the letters inside their tokens?

Models see subwords, not characters. We probe what LLMs know about token structure, and how much accuracy they lose under character- and token-level typos.

TKEval →

Does code generation transfer beyond English prompts?

Most code benchmarks are English-in, code-out. We pose the same problems in 23 natural languages and 12 programming languages and compare the results.

Publications

Papers, with the code and data to reproduce them

  1. 2026 arXiv preprint

    What Is a Repeated Token Worth? The Scaling Geometry of Multi-Epoch Pretraining

    Yekun Chai, Haoyi Xiong

    Against fresh data at equal compute, the cost of repetition follows one variable: extra epochs divided by unique tokens per parameter. A second epoch is worth nearly a fresh one, and repeats fall to half value past a critical epoch count that grows with the training budget per parameter but hardly with model size.

    • Paper
    • PDF
  2. 2026 arXiv preprint

    Finding the Move Is Not Winning the Game: XiangqiBench for Closed-Loop Evaluation of LLM Agents

    Yekun Chai, Qiwei Peng, Haoyi Xiong

    An LLM agent must deliver checkmate from 119 tactical endgames against an engine defender. Across 8,568 trajectories from 12 frontier LLMs, finding the right first move, high pass@k and self-simulated lines each overstate closed-loop success.

    Tokenization Falling Short: On Subword Robustness in Large Language Models

    Yekun Chai, Yewei Fang, Qiwei Peng, Xuhong Li

    Three test sets on what subword tokenization hides from LLMs: problems that need character access, probes of token structure, and robustness to character- and token-level typos.
