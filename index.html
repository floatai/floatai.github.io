PretrainingPreprint 2026

What is a repeated token worth?

Public text grows more slowly than compute. We price a repeated token against fresh data and find the epoch count past which it is worth half as much, across models from 14M to 2B parameters.

Multi-epoch scaling →

AgentsPreprint 2026

Can an agent finish the game, not just find the move?

Agents play xiangqi endgames to checkmate against an engine. Across 12 frontier LLMs, playing the right first move, pass@k and self-simulated lines each overstate closed-loop success.

XiangqiBench →

TokenizationFindings of EMNLP 2024

What do models know about the letters inside their tokens?

Models see subwords, not characters. We probe what LLMs know about token structure, and how much accuracy they lose under character- and token-level typos.

MultilingualLREC-COLING 2024

Does code generation transfer beyond English prompts?

Most code benchmarks are English-in, code-out. We pose the same problems in 23 natural languages and 12 programming languages and compare the results.
