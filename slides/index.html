Our mission

Measure what language models actually do.

Then release the data and code, so that anyone can check the answer.

One sentence to remember. Benchmarks often measure a proxy; we try to measure the outcome itself, and we publish everything needed to reproduce it.

How we work

Four habits behind every project

01

Measure the outcome, not a proxy

A correct first move is not a won game.

02

Change one thing at a time

Parallel prompts, matched compute, fixed tasks.

03

Report reliability with the average

pass^k beside pass@k; intervals beside point estimates.

04

Release what it takes to check us

Data and code with the paper; negative results welcome.

These habits explain the shape of every result that follows. Habit one is the thread through all four studies.

01 What is a repeated token worth?

A repeated token is worth half a fresh one after four to five epochs

  1. A second epoch is nearly free.Worth 0.87–1.02 fresh tokens at every budget.
  2. Scale epochs with data, not model size.The best epoch count stays near four.
  3. Spread repeats out.Back-to-back replay costs 0.46 bpb.
Proxy replaced: counting tokens seen. 175 matched runs. Blue lines are the largest models: gains flatten, then reverse after about four epochs. Reveal the three takeaways one by one.

02 Finding the move is not winning the game

Agents that find the right move rarely finish the game

  1. The right move is not a win.26.1% open correctly; 13.9% of those mate.
  2. Coverage is not reliability.Best model: 38.7% at least once, 5.9% every time.
  3. Self-simulation misleads.49.3% of defender replies leave the agent’s plan.
Proxy replaced: first-move accuracy. Dark bars are pass@3, bright bars pass^3. The gap between them is the story.

03 Tokenization falling short

Models know little about the characters inside their tokens

  1. Scale helps, but does not close the gap.Counting from the end peaks at 52%; subsequences near 4%.
  2. Typos bias every model.Character noise hurts more than token-level changes.
  3. Moderate BPE-dropout helps.p = 0.2 often beats the baseline.
Proxy replaced: word-level accuracy. The figure shows why spelling is hard: subword pieces do not add up to the word.

04 HumanEval-XL

With the task fixed, the prompt’s language still moves the score

  1. Language matters.Scala: 10 to 41, depending on the prompt’s language.
  2. One model leads everywhere.GPT-4 is best in all 276 language pairs.
  3. Code pretraining beats size.CodeGen2 16B beats GPT-3.5 in 9 of 12.
Proxy replaced: English-only coding scores. Every row is a programming language, every column a natural language; only the prompt’s language changes.
